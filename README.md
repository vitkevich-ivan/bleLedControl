# Luma BLE

Бесплатная PWA для управления Bluetooth-контроллерами семейства **LED LAMP**
(`LEDBLE-*`, `LEDDMX-*`, `LEDCAR-*`). Интерфейс рассчитан прежде всего на
iPhone и работает с BLE через бесплатный браузер
[Bluefy](https://apps.apple.com/app/bluefy-web-ble-browser/id1492822055).

## Возможности

- подключение напрямую к BLE, без аккаунта и облака;
- автоматический выбор протокола LEDBLE / LEDDMX;
- автоматическое переподключение и восстановление последнего состояния;
- питание, RGB-цвет, яркость, скорость и встроенные эффекты;
- светомузыка от микрофона телефона и аппаратный mic-режим контроллера;
- таймер выключения;
- настройка порядка RGB, числа пикселей и направления эффектов;
- проверка цветовых каналов и выбор порядка RGB для разных ревизий контроллера;
- офлайн-кэш после первого открытия.

## Разработка

```bash
npm install
npm run dev
```

Для Web Bluetooth страница должна быть открыта в безопасном контексте: на
компьютере подходит `localhost`, на iOS — опубликованный HTTPS-адрес в Bluefy.

```bash
npm test
npm run build
```

Собранная статика находится в `dist/` и подходит для GitHub Pages.

## iPhone

1. Установите бесплатный Bluefy из App Store.
2. Откройте в нём HTTPS-адрес приложения.
3. Включите лампу и нажмите «Найти лампу».
4. Выберите устройство с именем `LEDBLE-*`, `LEDDMX-*` или `LEDCAR-*`.

Safari на iOS не предоставляет Web Bluetooth, поэтому без Bluefy подключение к
лампе из PWA невозможно.
